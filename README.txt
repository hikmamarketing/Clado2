CLADO SOLUTIONS WEBSITE
=======================

Files:
- index.html       Homepage
- about.html       About Clado Solutions
- courses.html     Course listing with category filters
- course.html      Reusable course detail page (URL query selects course)
- projects.html    Practical learning / internship information
- contact.html     Contact details and WhatsApp enquiry form
- assets/style.css Main responsive styling
- assets/site.js   Navigation, filters and WhatsApp enquiry behaviour

HOW TO PREVIEW
Open index.html in a browser. The site uses remote Unsplash images and Google Fonts, so an internet connection is needed for those assets.

HOW TO PUBLISH
Upload the contents of this folder to your hosting public_html directory or the root of a GitHub Pages repository. Keep the assets folder in the same directory as the HTML files.

IMPORTANT BEFORE LAUNCH
1. Replace stock photography with Clado's actual classroom, faculty, students and lab images.
2. Verify phone, email, address and office hours.
3. Confirm current courses, syllabus, fees, schedules and internship details.
4. Add a privacy policy if collecting personal information or adding analytics.
5. The enquiry form currently opens WhatsApp; it does not save submissions to a database.
6. Review all claims and testimonials with Clado before publishing.
